## Why

Most risk in a Python app comes from its dependencies. Upstream only runs dependency review in some cases. We run it on every requirements change.

## Tasks

- [ ] When `requirements-changed` is true, run `actions/dependency-review-action` (pinned in the README) with `fail-on-severity: high`.
- [ ] Run `pip-audit -r requirements.txt` on the core requirements on every run. Use `--format json` and save the report.

## Acceptance criteria

- [ ] A PR pinning a dependency version with a known high CVE fails.
- [ ] A clean PR passes.

## Artifacts

`pip-audit.json`.
