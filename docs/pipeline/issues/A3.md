## Why

It produces the installable package, so storing artifacts is a real step in the pipeline. The SBOM (C5) and the release (D5) both use it.

## Tasks

- [ ] Run `uv build` to produce `dist/*.whl` and `dist/*.tar.gz`.
- [ ] Write `dist/SHA256SUMS` with `sha256sum`.
- [ ] Upload `dist/` with `actions/upload-artifact`: name `dist-${{ github.sha }}`, `retention-days: 14`, `if-no-files-found: error`.
- [ ] Expose the artifact name as a workflow output for C5 and D5.

## Acceptance criteria

- [ ] The artifact is downloadable from the run, and `sha256sum -c SHA256SUMS` passes.
- [ ] The build fails if no wheel is produced.
