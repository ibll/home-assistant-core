**Workstream:** Member B: tests and contract safety
**Week:** 2
**Depends on:** A1
**Checklist items:** Q15, N6

## Why

The full suite takes hours. Testing just what changed gives feedback in minutes. Upstream CI still runs the full suite.

## Tasks

- [ ] In `team-test.yml`, set up Python 3.14 (`setup-uv-python`) and install `requirements_test.txt` plus the requirements of each changed integration (see `script/install_integration_requirements.py`).
- [ ] Run `pytest tests/components/<domain>` for each domain in `inputs.integrations`, with `--junitxml=junit.xml` and `--cov=homeassistant.components.<domain> --cov-report=xml`.
- [ ] If the list is empty, skip cleanly.
- [ ] Keep the `team-inject-failure` step (`stage: test`).

## Acceptance criteria

- [ ] A PR breaking a test in `tests/components/demo` fails the test stage.
- [ ] A docs-only PR runs no integration tests.

## Artifacts

`junit.xml` and `coverage.xml` (with B3).
