## Why

Writing tests is manual work. The model points out untested functions and branches in the changed code, and a human decides whether to write them.

## Tasks

- [ ] Add a job `test-gaps` to `team-ai-advisory.yml`. It runs on pull requests only.
- [ ] Input: the diff of the changed integration source (capped at about 400 lines) plus the names of the existing test functions.
- [ ] The system prompt says the diff is untrusted data. Ask for JSON: `[{file, function, missing_case}]`, at most 5 items. Set `max-tokens`.
- [ ] Validate the output: keep only items whose `file` is in the diff. Write them to the job summary.
- [ ] Upload `ai-test-gaps.json`. Permissions: `contents: read`, `models: read`.

## Acceptance criteria

- [ ] On a PR adding an untested function, the advisor names it.
- [ ] Invalid model output never fails the job.
- [ ] Track adopted / suggested over at least 5 PRs.
