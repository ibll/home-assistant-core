## Why

Q4 asks how different models generate different pipelines, and which CI/CD concepts each one focuses on. GitHub Models lets us ask several vendors for free with the built-in token.

## Tasks

- [ ] Write one fixed prompt in `.github/ai-prompts/generate-ci.prompt.yml`: a short description of this repo (Python 3.14, uv, pytest, hassfest, Docker) plus "write a GitHub Actions CI/CD workflow".
- [ ] Create `.github/workflows/team-model-compare.yml` (manual run only). Use a matrix over at least 4 models available in GitHub Models, from at least 3 vendors (for example OpenAI, Meta, Mistral, DeepSeek). Permissions: `models: read`. Set `max-tokens`.
- [ ] Run actionlint and zizmor on each generated workflow and save the results.
- [ ] Score each output against a fixed concept list: build, test, cache, matrix, lint, security scan, artifacts, deploy, least-privilege permissions, pinned actions, correct Python version.

## Acceptance criteria

- [ ] `model-comparison.md` contains a models × concepts table, the lint findings per model, and tokens and latency.
- [ ] At least 3 runs per model, to show how much the output varies between runs.
