## Why

Storing the image in a registry is the artifact-storage and delivery step. Signing proves the image came from our pipeline.

## Tasks

- [ ] Log in to `ghcr.io` with `GITHUB_TOKEN`. Push `ghcr.io/ibll/home-assistant-core:<sha>` and `:dev` (use `docker/metadata-action` for the tags).
- [ ] Sign the image by digest with keyless `cosign` (`sigstore/cosign-installer`, pinned).
- [ ] Give **this job only** `packages: write` and `id-token: write`, each with a comment.
- [ ] Output `image` as `ghcr.io/...@sha256:<digest>` (the stub output already exists).

## Acceptance criteria

- [ ] The image is visible under the repo's Packages.
- [ ] `cosign verify` with the GitHub OIDC issuer and this workflow's identity passes. Paste the command and its output into the docs.
