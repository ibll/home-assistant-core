## Why

The pipeline is only as good as several things that live outside its YAML,
and nothing notices when they drift:

- **Settings:** the `staging` reviewer and the required checks on `main`
  (L1). Anyone with admin access can remove them, and the pipeline keeps
  passing.
- **Docs:** the README's pinned-action table, stage list and rules can stop
  matching the workflows.
- **Tool versions:** L0 passed under zizmor 1.16.3 while the repo pins
  1.30.1, which reported 10 findings. A check run with the wrong version
  isn't evidence.
- **Upstream:** PR #30 removed the upstream workflows from the fork. We no
  longer see new checks Home Assistant adds upstream.

## Tasks

- [ ] Create `.github/workflows/team-drift.yml`: weekly schedule plus manual runs. Permissions `contents: read` and `actions: read` only.
- [ ] **Settings drift:** `gh api repos/$GITHUB_REPOSITORY/environments/staging` must list a required reviewer. `gh api repos/$GITHUB_REPOSITORY/rules/branches/main` must require a pull request and the `team-pipeline` checks. Fail when either is missing.
- [ ] **Docs drift:** every `team-*.yml` file appears in `docs/pipeline/README.md` and vice versa. Every `uses: owner/repo@<sha>` in `team-*` files appears in the README's pin table with the same SHA. Fail on a mismatch.
- [ ] **Tool-version drift:** the zizmor `rev` in `.pre-commit-config.yaml` matches the version the docs and C4 use. Fail on a mismatch.
- [ ] **Upstream drift (report only):** use `gh api repos/home-assistant/core/compare/<fork point>...dev` to list upstream commits since the fork that touch `.github/workflows/`, `requirements*.txt` or `pyproject.toml`. Write them to the report, without failing.
- [ ] Write `drift-report.md` to the job summary and as an artifact.

## Acceptance criteria

- [ ] Removing the `staging` reviewer (on a test basis, then restoring it) makes the next run fail. Link the run.
- [ ] A PR that adds an action without updating the README pin table fails.
- [ ] The report lists upstream workflow and requirement changes since the fork.
