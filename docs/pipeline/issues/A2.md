**Week:** 2
**Depends on:** A1
**Checklist items:** Q9, Q12

## Why

It catches style and integration-metadata errors in under a minute, before the slower tests run.

## Tasks

- [ ] Set up Python 3.14 with `./.github/actions/setup-uv-python`, using the uv version from `requirements.txt`.
- [ ] Install the pinned linters from `requirements_test_pre_commit.txt`.
- [ ] Run `ruff check` and `ruff format --check` on the changed Python files, and `codespell` and `yamllint` on the changed files.
- [ ] For each changed integration, run `python -m script.hassfest --integration-path homeassistant/components/<domain>`.
- [ ] Keep the `team-inject-failure` step (`stage: lint`).

## Acceptance criteria

- [ ] A PR with a ruff error fails the build stage, and the error shows as an annotation on the file.
- [ ] A clean PR passes in under 3 minutes with a warm cache.
