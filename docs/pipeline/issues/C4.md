## Why

The pipeline itself is attack surface. The most common GitHub Actions attacks are script injection, unpinned actions and over-broad tokens.

## Tasks

- [ ] When `workflows-changed` is true, run zizmor (`--pedantic`) and actionlint on `.github/workflows/team-*.yml` and fail on findings.
- [ ] Add a small check that every `uses:` in `team-*` files is a 40-character SHA or a local `./` path.
- [ ] Add `.github/workflows/team-scorecard.yml` with `ossf/scorecard-action` (pinned), weekly, uploading SARIF.

## Acceptance criteria

- [ ] A PR that adds `uses: actions/checkout@v7` fails.
- [ ] Scorecard results appear under Security → Code scanning.

## Artifacts

`zizmor.sarif` and `scorecard.sarif`.
