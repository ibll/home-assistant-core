## Why

The frontend, the mobile apps and every integration depend on the core's REST and WebSocket APIs and its entity and config-entry helpers. This fixed suite runs on *every* change to show we don't break them (Q13).

## Tasks

- [ ] Always run `tests/test_core.py`, `tests/test_config_entries.py`, `tests/components/api`, `tests/components/websocket_api` and `tests/helpers/test_entity.py`. Tune the list to stay under ~8 minutes.
- [ ] These use syrupy snapshots (`.ambr` files). An API shape change must fail the run, not update a snapshot. Never pass `--snapshot-update` in CI.
- [ ] Run it in parallel with B1 (a separate job in the same stage).

## Acceptance criteria

- [ ] A deliberate change to a REST API response (on a throwaway branch) fails the contract suite. Link the run.
- [ ] A green run takes 8 minutes or less.
