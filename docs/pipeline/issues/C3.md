## Why

Q11 asks whether we track *every new dependency the AI added* and check it. AI tools also sometimes invent package names that don't exist, which attackers then register ("slopsquatting").

## Tasks

- [ ] Diff `requirements*.txt`, `pyproject.toml` and every `manifest.json` `requirements` list against the base. Collect the added or changed packages.
- [ ] For each one, check that it exists on PyPI, then record its first release date, license (reuse `script/licenses.py`) and pip-audit result.
- [ ] Check whether the commit that added it carries an `AI-Assisted:` or `Co-Authored-By: <AI>` trailer, and record `ai_added: true/false`.
- [ ] Fail if the package does not exist, has a high CVE, or has a license `script/licenses.py` rejects.
- [ ] Agree on the team convention: AI-written commits carry an `AI-Assisted: <tool>` trailer.

## Acceptance criteria

- [ ] `new-dependencies.json` lists every new package with its fields.
- [ ] A PR adding a made-up package name fails.
