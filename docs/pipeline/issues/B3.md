## Why

A red X is not enough. Reviewers need to see which test failed and how much of the changed code is covered.

## Tasks

- [ ] Upload `junit*.xml` and `coverage.xml` as artifacts (`if: ${{ !cancelled() }}`, so they upload on failure too).
- [ ] Render a test summary in `$GITHUB_STEP_SUMMARY`, either with a pinned reporter action or a short Python script.
- [ ] Coverage gate: fail if the changed integrations are under 90% covered, the Home Assistant standard. Use `coverage report --fail-under`.

## Acceptance criteria

- [ ] The artifacts are present on both green and red runs.
- [ ] The coverage gate fails a PR that adds untested code.
