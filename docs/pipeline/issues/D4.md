## Why

Home Assistant is self-hosted, so our "deployment" is starting the signed image in a gated `staging` environment and proving it serves requests.

## Tasks

- [ ] In `team-deploy.yml` (it already uses `environment: staging`), `docker run -d -p 8123:8123` the image from `inputs.image`.
- [ ] Poll until healthy: up to 3 minutes for `curl -fsS http://localhost:8123/manifest.json`.
- [ ] Smoke test: `GET /manifest.json` returns 200 with JSON (content type `application/manifest+json`), and `GET /api/onboarding` returns 200 on a fresh instance.
- [ ] Always upload `docker logs` as an artifact, even on failure.
- [ ] Keep the `team-inject-failure` step (`stage: smoke`).

## Acceptance criteria

- [ ] A run waits for the tech lead's approval, then passes the smoke test.
- [ ] `inject_failure=smoke` fails here.
