- Used `type=ref,event=branch` instead of a hard-coded `:main` tag, so a

  workflow. The docs show the stricter exact identity for `main`.

  registry manifest instead of the uncompressed size on the runner.
- Edited `team-pipeline.yml`, which the tech lead owns, because the
