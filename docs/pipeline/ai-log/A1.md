## Could I explain this without the AI?

The workflow checks out the full repository history, chooses the pull request
base SHA or push-before SHA as the comparison base, and compares it with the
current commit. It extracts unique integration domains from changed integration
and integration-test paths and sets booleans for core, requirements, and
workflow changes, then publishes those values as reusable-workflow outputs, a
job summary, and the `changes.json` artifact.
