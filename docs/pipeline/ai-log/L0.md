Q2/Q12):

  obvious fix, reusing the caller's group name, would have made each stage
  cancel itself, because `github.workflow` in a called workflow is the

  run is still in progress. It was changed to fetch each failed job's log by
  job ID.

  serves `/manifest.json`, the URL D4's smoke test checks. The frontend
  package was added to the fallback.
